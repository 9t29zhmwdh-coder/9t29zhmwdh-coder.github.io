# Security Policy

## Reporting a vulnerability

This is a static website. If you find a security issue (e.g. malicious script injection via a PR),
please report it privately via the GitHub repository's Security tab or contact the maintainer directly.

We aim to respond within 72 hours.

## Content Security Policy

The policy is a meta tag in `index.html` and is generated by `scripts/update-csp.py`. Run it after every change to an inline script (`python3 scripts/update-csp.py`, `--check` to verify). GitHub Pages cannot send HTTP headers, so header-only protections (HSTS, `X-Frame-Options`, `frame-ancestors`) are not available.
