Datenschutzerklärung

Stand: 30. Oktober 2026

1. Verantwortlicher

Rafael Yilmaz, RayStudio, Schweiz. Kontakt: Kontaktformular auf raystudio.ch.

2. Das Wichtigste

Die Seite setzt keine Cookies ein, nutzt keine Analyse- oder Tracking-Dienste und blendet keine Werbung ein. Daten gehen nur an Dritte, wenn du ein Formular oder eine Beispielfunktion benutzt, und das steht unten bei jeder Funktion.

3. Hosting bei GitHub Pages

Die Website liegt bei GitHub Pages (GitHub, Inc., Microsoft, USA). GitHub kann beim Aufruf technische Daten wie IP-Adresse, Zeitpunkt und Browser in Server-Protokollen erfassen. Darauf habe ich keinen Einfluss. Siehe die Datenschutzerklärung von GitHub.

4. Kontaktformular

  • Daten: Name, E-Mail-Adresse und Nachricht.
  • Zweck: Ich nutze sie nur, um dir zu antworten.
  • Weg: Dein Browser sendet sie an einen Cloudflare Worker, der sie über Resend per E-Mail an mein Postfach weiterleitet. Der Worker speichert nichts. Vor dem Versand prüft er, ob die Domain deiner E-Mail-Adresse Post empfangen kann. Dazu fragt er nur den Teil nach dem @ beim DNS-Dienst von Cloudflare ab, nie Name oder Nachricht.
  • Aufbewahrung: Ich bewahre die Nachricht so lange auf, wie die Anfrage dauert, und lösche sie danach, spätestens nach zwölf Monaten, ausser eine gesetzliche Pflicht verlangt etwas anderes.
  • Eine Nachricht über ein GitHub-Issue ist öffentlich sichtbar und unterliegt den Regeln von GitHub.

5. Bot-Schutz mit Cloudflare Turnstile

Das Formular ist mit Cloudflare Turnstile gegen Bots geschützt. Das Skript von Cloudflare wird erst geladen, wenn du ins Formular klickst, nicht beim blossen Lesen. Cloudflare erhält dafür deine IP-Adresse und Browser-Signale.

6. Wetterkachel

Sobald die Wetterkachel im Smart-Home-Beispiel ins Bild rückt, fragt dein Browser beim Cloudflare Worker an. Cloudflare leitet im Worker aus deiner IP-Adresse einen groben Ort ab (Stadtebene, auf rund 10 km gerundet). Es gibt keine Standortabfrage, und nichts wird gespeichert. An den Wetterdienst MET Norway (api.met.no) gehen nur diese gerundeten Koordinaten, nie deine IP-Adresse.

7. RepoLedger-Beispiel

Sobald das Beispiel im Bereich Developer ins Bild rückt, lädt dein Browser öffentliche Repository-Angaben bei der GitHub-API (api.github.com). GitHub erhält dabei deine IP-Adresse. Die Antworten merkt sich dein Browser 15 Minuten lokal. An mich geht nichts.

8. Mein System, DNS-Check und Mail-Check

Die Anzeige «Mein System» liest Werte wie Betriebssystem, Browser und Bildschirm nur lokal in deinem Browser. Es wird nichts gesendet oder gespeichert, und es gibt keine Abfrage deiner öffentlichen IP-Adresse. DNS- und Mail-Check laufen nur, wenn du sie startest. Sie fragen die Domain, die du eingibst, bei Google (8.8.8.8) oder Cloudflare (1.1.1.1) ab. Dort gelten deren Datenschutzbestimmungen.

9. Schriften und Links

Die Schriften liegen auf dieser Website selbst, es gibt keine Anfrage an Google Fonts. Auf verlinkten Seiten gelten deren Datenschutzbestimmungen.

10. Weitergabe ins Ausland

Einige Anbieter sitzen in den USA (GitHub/Microsoft, Cloudflare, Resend, Google), MET Norway in Norwegen. Dort kann das Datenschutzniveau von dem der Schweiz abweichen. Cloudflare stützt die Übermittlung auf das Swiss-U.S. Data Privacy Framework, Resend auf Standardvertragsklauseln mit Schweiz-Zusatz. Bei den übrigen Anbietern gilt das Framework oder es gelten Standardvertragsklauseln.

11. Deine Rechte

Du kannst Auskunft über deine Daten verlangen sowie Berichtigung, Löschung, Einschränkung oder Herausgabe. Schreib mir dazu über das Kontaktformular auf raystudio.ch. Du kannst dich zudem beim Eidgenössischen Datenschutz- und Öffentlichkeitsbeauftragten (edoeb.admin.ch) beschweren.

12. Änderungen

Ändert sich etwas an der Website, passe ich diese Erklärung an. Es gilt die Fassung, die hier steht.

Privacy policy

Last updated: 30 October 2026

1. Controller

Rafael Yilmaz, RayStudio, Switzerland. Contact: contact form on raystudio.ch.

2. In short

This site sets no cookies, uses no analytics or tracking and shows no ads. Data goes to third parties only when you use a form or a demo feature, and each one is described below.

3. Hosting at GitHub Pages

The website is hosted on GitHub Pages (GitHub, Inc., Microsoft, USA). GitHub may record technical data such as IP address, time and browser in server logs when you visit. I have no influence on that. See GitHub's privacy statement.

4. Contact form

  • Data: name, e-mail address and message.
  • Purpose: I use them only to reply to you.
  • Route: your browser sends them to a Cloudflare Worker, which forwards them by e-mail through Resend to my mailbox. The worker stores nothing. Before sending, it checks whether the domain of your address can receive mail. For that it asks Cloudflare's DNS service only for the part after the @, never your name or message.
  • Retention: I keep the message as long as the request lasts and delete it afterwards, after twelve months at the latest, unless a legal duty requires otherwise.
  • A message sent as a GitHub issue is publicly visible and subject to GitHub's rules.

5. Bot protection with Cloudflare Turnstile

The form is protected against bots by Cloudflare Turnstile. Cloudflare's script loads only when you click into the form, not while you merely read. Cloudflare receives your IP address and browser signals for that.

6. Weather tile

When the weather tile in the smart home example scrolls into view, your browser asks the Cloudflare Worker. Inside the worker, Cloudflare derives a coarse place (city level, rounded to about 10 km) from your IP address. There is no location prompt and nothing is stored. Only these rounded coordinates, never your IP address, go on to the weather service MET Norway (api.met.no).

7. RepoLedger example

When the example in the Developer section scrolls into view, your browser loads public repository information from the GitHub API (api.github.com). GitHub receives your IP address. Your browser keeps the answers locally for 15 minutes. Nothing goes to me.

8. My System, DNS check and mail check

The "My System" panel reads values such as operating system, browser and screen only locally in your browser. Nothing is sent or stored, and your public IP address is not looked up. The DNS and mail checks run only when you start them. They query the domain you enter at Google (8.8.8.8) or Cloudflare (1.1.1.1), whose privacy policies apply.

9. Fonts and links

The fonts are served from this site itself, with no request to Google Fonts. On linked sites, their privacy policies apply.

10. Transfers abroad

Some providers are based in the USA (GitHub/Microsoft, Cloudflare, Resend, Google), MET Norway in Norway. The level of data protection there may differ from Switzerland. Cloudflare bases the transfer on the Swiss-U.S. Data Privacy Framework, Resend on standard contractual clauses with a Swiss addendum. For the other providers, the framework or standard contractual clauses apply.

11. Your rights

You can ask for information about your data and for correction, deletion, restriction or handover. Write to me through the contact form on raystudio.ch. You can also complain to the Swiss Federal Data Protection and Information Commissioner (edoeb.admin.ch).

12. Changes

If something on the website changes, I update this policy. The version published here applies.
