# Fonts

Self-hosted web fonts of raystudio.ch (variable fonts, WOFF2, subsets `latin` and `latin-ext`).

| Font | Source | License |
|---|---|---|
| Space Grotesk | Google Fonts | SIL Open Font License 1.1 |
| Inter | Google Fonts | SIL Open Font License 1.1 |
| JetBrains Mono | Google Fonts | SIL Open Font License 1.1 |

The files were taken unchanged from Google Fonts (2026-10-13). The `@font-face` rules are inline in `index.html`. The OFL allows self-hosting and redistribution; the font files must not be sold on their own.
